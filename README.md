# argon2

Argon2 ([RFC 9106](https://www.rfc-editor.org/rfc/rfc9106.html)) for Go: the
API and the code of `golang.org/x/crypto/argon2`, plus an Advanced SIMD
(NEON) kernel for the BLAMKA compression function on arm64, where the
standard package runs scalar Go.

```go
import "github.com/go-encryptions/argon2"

key := argon2.IDKey(password, salt, 3, 64*1024, 4, 32)
```

`Key` and `IDKey` are the same functions with the same results as in
`golang.org/x/crypto/argon2`; only the speed differs.

## Kernels

| platform | BLAMKA |
|---|---|
| arm64 with Armv8.2 SHA-3 (every Apple core, Neoverse V1 and later) | NEON, `XAR` for each XOR-and-rotate |
| arm64 | NEON |
| amd64 | SSE4.1 (unchanged from x/crypto) |
| loong64 | LSX (unchanged from x/crypto) |
| anything else | portable Go |

The arm64 kernels are generated by `tools/genblamka`: two rows of the block are
processed at once and their instruction streams interleaved. CI checks that the
committed assembly is the generator's output.

## Correctness

The x/crypto test vectors, a differential test of every kernel against the
portable code on random blocks (including `out` aliasing an input, which
Argon2's address blocks do), and a test of `Key` and `IDKey` against
`golang.org/x/crypto/argon2` over several parameter sets.

## Performance

Apple M4 Max, one core, Argon2id t=3, m=64 MiB, p=1:

| | ms |
|---|---:|
| this package | 41.6 |
| `golang.org/x/crypto/argon2` | 93.6 |
